# 📝 我的待办清单

一个超简单的待办清单网页应用——纯 HTML / CSS / JavaScript，**双击 `index.html` 就能在浏览器里打开使用**，不用安装任何东西。

这个项目是专门用来**练习 Git** 的。配套教程见 [`TUTORIAL.md`](./TUTORIAL.md)。

## 功能

- ✅ 添加任务
- ✅ 勾选标记完成
- ✅ 删除任务
- ✅ 自动保存（刷新页面也不会丢）

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面的骨架（结构） |
| `style.css` | 页面的长相（样式） |
| `app.js` | 页面的大脑（逻辑） |
| `README.md` | 就是你正在看的这份说明 |
| `TUTORIAL.md` | 手把手 Git 实操教程（命令行版） |
| `TUTORIAL-VSCODE.md` | 在 VS Code 里点按钮用 Git（图形界面版） |

## 怎么运行

直接用浏览器打开 `index.html` 即可。
